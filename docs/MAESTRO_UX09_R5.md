# UX09 R5: trazabilidad de implementación

La composición de finca utiliza únicamente variables con dos o más categorías utilizables del motor de participación. Una categoría abre su directorio de suertes; el ámbito y búsqueda se conservan al volver de la ficha. La vista Suertes solicitada expresamente restablece el ámbito. Las categorías de corte corresponden a rangos acreditados, no al número exacto de cada suerte.

El gráfico de Resumen obtiene las zonas y sus áreas del agregador oficial. En la generación 2026.10.25-aforo.1101, las cuatro zonas totalizan 9.574,66 ha, concordantes con CRONO_DATA.global.area (diferencia por precisión flotante inferior a 0,01 ha). El motor no expone summary.activeArea en esta generación; se contrasta la suma de grupos oficiales con el total global sin fabricar otro universo. Si divergen se muestra advertencia.

La comparación visual usa como referencia el commit 06044658df86c6b6094fa8051d402841095b9ef6. El manifiesto runtime se regeneró por los únicos cambios de CSS y adaptador UX; no se modificaron motores ni datos oficiales.
